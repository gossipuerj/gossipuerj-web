# 🕵️‍♀️ GlossipUerj - A Rede Social da UERJ 🕵️‍♂️

## 🚀 Sobre o Projeto

O GlossipUerj foi criado para ser o ponto de encontro digital do campus. Com uma estética **ArtPop** vibrante e moderna (misturando Neon, Cyberpunk e Glassmorphism), o projeto oferece uma experiência de usuário premium e fluída.

> [!IMPORTANT]
> **Nota de Desenvolvimento:** Este projeto teve sua estrutura inicial e lógica de interface desenvolvidas com o auxílio da **Inteligência Artificial (Antigravity da DeepMind)**. Essa abordagem foi adotada estrategicamente para **otimizar o tempo de desenvolvimento**, permitindo que o foco fosse direcionado para o design e para a experiência do usuário da UERJ de forma ágil e eficiente.

---

## ✨ Funcionalidades Principais

- **🕵️‍♀️ Feed de Fofocas**: Poste fofocas, desabafos e paqueras de forma anônima. O sistema conta com categorias e indicação de alvos específicos.
- **💖 Galeria de Crushes**: Encontre alunos da UERJ em uma grade moderna e interativa. Filtre por curso (todos os 80+ da UERJ), gênero e orientação sexual.
- **💬 Chat Interativo**: Sistema de mensagens estilo WhatsApp (Dark Mode) para conversar com seus matches em tempo real (simulado).
- **👤 Perfil Personalizável**: Gerencie seus dados, curso oficial e presença no app com uma interface intuitiva.
- **📦 Mock Architecture**: O sistema está pronto para produção com dados simulados, o que permite o desenvolvimento da UI sem a necessidade de um servidor backend ativo no momento.

## 🛠️ Tecnologias Utilizadas

- **Core**: Next.js 15+ (App Router)
- **Idioma**: TypeScript
- **Estilo**: Vanilla CSS (com forte uso de CSS Variables e Glassmorphism)
- **Ícones**: Lucide React
- **Design System**: ArtPop / Cyberpunk Aesthetic

## 📦 Como Rodar o Projeto

Para visualizar a aplicação em seu ambiente local:

1. **Instale as dependências**:
   ```bash
   npm install
   ```

2. **Inicie o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```

3. **Acesse no navegador**:
   [http://localhost:3000](http://localhost:3000)

## 🗺️ Futuro do Projeto

O GlossipUerj foi construído com uma camada de abstração de API (`src/lib/api.ts`). Quando o backend estiver finalizado, basta configurar a URL base para que os dados simulados sejam substituídos por interações reais com banco de dados.
